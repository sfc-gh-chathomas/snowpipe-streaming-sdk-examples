# Demos

End-to-end demos built on the Snowpipe Streaming SDK. Each one is self-contained, with
its own setup, authentication, and presenter notes.

| Demo | What it shows |
|---|---|
| [Elastic Fleet](./elastic-fleet-demo) | 250 independent SDK clients stream synthetic router telemetry into one table through Elastic channels; a read-only Snowflake App Runtime dashboard queries it live, with a presenter runbook |
